# Code de conduite

Ce projet adopte le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : bienveillance, respect des désaccords techniques argumentés, aucune forme de harcèlement. Les signalements se font de façon confidentielle auprès des mainteneurs, via les Security Advisories du dépôt.
