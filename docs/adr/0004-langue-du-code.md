# ADR-0004 : Code en anglais, produit et docs en français

- **Statut** : Accepté
- **Date** : 2026-11-10

## Décision
- Les identifiants Python (modules, classes, fonctions) sont **en anglais**, ce qui facilite les contributions internationales et suit les conventions de l'écosystème.
- Les docstrings, les messages affichés, la documentation, les prédicats de la base (`est_un`, `partie_de`…) et les commits sont **en français**.

## Conséquences
- (+) Un code lisible par tous, un produit pensé pour un public francophone.
- (−) Deux langues coexistent : ce document fixe la frontière entre elles.
