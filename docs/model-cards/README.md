# Fiches modèles

Chaque réseau de neurones entraîné (à partir de M2) aura une fiche indiquant :
- l'objectif et le périmètre d'usage ;
- les données d'entraînement (provenance, licence, taille) ;
- l'architecture, le nombre de paramètres, la graine et l'empreinte SHA-256 des poids ;
- les métriques par banc d'essai dans `evals/` ;
- les limites, biais connus et modes d'échec.

Aucune fiche pour l'instant : M1 ne contient aucun réseau.
